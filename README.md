## 如何启动

在 Windows 项目目录运行（需要 Python 3.14）：

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 操作方式

![操作教程](display/control.png)

Esc | 打开设置
